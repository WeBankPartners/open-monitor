# 基础镜像构建命令

本文档记录了各个版本的基础镜像构建命令。

---

## v1.0

### 步骤 1: 运行基础容器
```bash
docker run --name open-monitor-base -itd --privileged=true platten/alpine-oracle-jre8-docker /bin/sh
```

### 步骤 2: 在容器内创建目录
```bash
docker exec -it open-monitor-base /bin/sh
# 在容器内执行
mkdir -p /app/monitor
exit
```

### 步骤 3: 复制文件到容器
```bash
docker cp alertmanager-0.21.0.linux-amd64.tar.gz open-monitor-base:/app/monitor/
docker cp prometheus-2.20.1.linux-amd64.tar.gz open-monitor-base:/app/monitor/
```

### 步骤 4: 在容器内解压和配置
```bash
docker exec -it open-monitor-base /bin/sh
# 在容器内执行
cd /app/monitor
tar zxf prometheus-2.20.1.linux-amd64.tar.gz
tar zxf alertmanager-0.21.0.linux-amd64.tar.gz
mv prometheus-2.20.1.linux-amd64 prometheus
mv alertmanager-0.21.0.linux-amd64 alertmanager
rm -f *.gz
exit
```

### 步骤 5: 导出、导入和推送镜像
```bash
docker export -o prometheus-2.20.1.tar open-monitor-base
docker import prometheus-2.20.1.tar prometheus-base:v1.0
docker login --username=XXXX ccr.ccs.tencentyun.com
# password: XXXX
docker tag prometheus-base:v1.0 ccr.ccs.tencentyun.com/webankpartners/wecube-prometheus:v1.0
docker push ccr.ccs.tencentyun.com/webankpartners/wecube-prometheus:v1.0
```

## v1.4

### 步骤 1: 运行基础容器
```bash
docker run --name open-monitor-base -itd --privileged=true ccr.ccs.tencentyun.com/webankpartners/wecube-prometheus:v1.2 /bin/sh
```

### 步骤 2: 在容器内执行操作（包含 sudo 安装和配置）
```bash
docker exec -it open-monitor-base sh
```

在容器内执行以下命令：
```bash
cd /app/monitor && \
mv prometheus prometheus_tmp && \
mv alertmanager alertmanager_tmp && \
addgroup -S apps -g 6000 2>/dev/null || true && \
adduser -S app -u 6001 -G apps 2>/dev/null || true && \
chown -R app:apps /app/monitor && \
echo "✅ 目录重命名和用户创建完成，权限已设置"

# 安装 sudo（用于提权，允许 app 用户临时切换到 root）
apk add --no-cache sudo && \
echo "app ALL=(ALL) NOPASSWD: ALL" > /etc/sudoers.d/app && \
chmod 0440 /etc/sudoers.d/app && \
visudo -c && \
echo "✅ sudo 安装和配置完成"

exit
```

### 步骤 3: 导出、导入和推送镜像
```bash
docker export -o prometheus-3.4.2.tar open-monitor-base
docker import prometheus-3.4.2.tar prometheus-base:v1.4
docker login --username=XXXX ccr.ccs.tencentyun.com
# password: XXXX
docker tag prometheus-base:v1.4 ccr.ccs.tencentyun.com/webankpartners/wecube-prometheus:v1.4
docker push ccr.ccs.tencentyun.com/webankpartners/wecube-prometheus:v1.4
docker rm -f open-monitor-base
rm -f prometheus-3.4.2.tar
```

## 说明

- 所有版本的基础镜像都基于 `platten/alpine-oracle-jre8-docker`
- v1.0: Prometheus 2.20.1, Alertmanager 0.21.0
- v1.1: Prometheus 2.24.1, Alertmanager 0.21.0（添加 tzdata）
- v1.2: Prometheus 3.4.2, Alertmanager 0.21.0（添加 tzdata）
- v1.4: Prometheus 3.4.2, Alertmanager 0.21.0（添加 tzdata、sudo、app 用户、目录重命名）

**注意**: 请将命令中的 `XXXX` 替换为实际的用户名和密码。
